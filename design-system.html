Is our design system AI-ready?

DescripciónDescription

Un marco de auditoría de seis dimensiones para comprobar la preparación de un sistema de diseño mayorista para flujos asistidos por IA.A six-dimension audit framework to check how ready a wholesale design system is for AI-assisted workflows.

Definición del problemaProblem statement

La IA es tan fiable como el sistema en el que se apoya. En nuestras herramientas mayoristas, el sistema de diseño, su capa front-end y Figma habían divergido, por lo que no había una única fuente de verdad desde la que la IA pudiera construir.AI is only as reliable as the system underneath it. In our wholesale tools, the design system, its front-end layer and Figma had drifted apart, so there was no single source of truth for AI to build from.

Qué creéWhat I created

Una guía de puntuación de 0 a 5 en seis dimensiones: arquitectura de tokens, APIs de componentes, paridad diseño–código, estructura, gobernanza y preparación para flujos con IA. Después audité el sistema de diseño y su capa front-end directamente desde el código, en lugar de preguntar a otras personas, y actué sobre lo que encontré:A 0–5 scoring guide across six dimensions: token architecture, component APIs, design–code parity, structure, governance and AI workflow readiness. Then I audited the design system and its front-end layer straight from the code instead of asking around, and acted on what I found:

  • Conecté Button y 671 iconos mediante Code Connect (672 correspondencias), integrados en main.Connected Button and 671 icons through Code Connect (672 mappings), merged to main.
  • Creé un kit de prototipado con componentes reales.Built a prototyping kit with real components.
  • Creé un ejemplo completo de login.Built a complete login example.

Aprendizajes claveKey learnings

  • Coexisten dos generaciones de implementación. Algunas herramientas utilizan solo el sistema de diseño base; otras, la capa front-end construida sobre él.Two generations of implementation coexist. Some tools run on the base design system alone, others on the front-end layer built on top of it.
  • La capa front-end se utiliza en tres versiones y ninguna es la más reciente. Una herramienta también incorporó una librería UI de terceros, lo que supone un segundo sistema de diseño dentro de un mismo producto.The front-end layer runs in three versions, and none is the latest. One tool also brought in a third-party UI library, which makes it a second design system inside one product.
  • Figma y código no coinciden. Button tiene una variante CTA en Figma que no existe en código. Tres iconos existen solo en Figma y seis solo en código. Un enlace al código fuente está roto porque su paquete ya no se publica.Figma and code don’t match. Button has a CTA variant in Figma that doesn’t exist in code. Three icons exist only in Figma and six only in code. One source link is broken because its package is no longer published.
  • La gobernanza es la verdadera carencia. El plan de convergencia propuesto por los desarrolladores front-end tiene una envergadura similar a la migración a React, por lo que nadie lo aprobaría tal como está planteado.Governance is the real gap. The convergence plan the FE devs proposed is as big as the React migration, so nobody would approve it as written.
