Adidas

AI-native case management

Definición del problemaProblem statement

Los agentes de atención al cliente alternan entre herramientas desconectadas para resolver un mismo caso, aumentando el tiempo de atención y generando fricción para agentes y clientes.Customer service agents switch between disconnected tools to resolve a single case, increasing handling time and creating friction for both agents and customers.

DescripciónDescription

Diseñar el futuro centro de atención: de Salesforce a Amazon Connect, con un proceso basado en contexto compartido y prototipos en código. Piloto: paquetes perdidos. Objetivo: reducir un 20% el tiempo medio de atención.Designing the future contact center: from Salesforce to Amazon Connect, with a process grounded in shared context and coded prototypes. Pilot: lost parcels. Goal: reduce average handling time by 20%.

Qué creéWhat I created

  • Un espacio de contexto compartido que reúne investigación previa, feedback de agentes y evaluaciones heurísticas.A shared context space bringing together existing research, agent feedback, and heuristic evaluations.
  • El journey del agente para el piloto de paquete perdido y un card sorting con más de 50 agentes de distintos mercados.An agent journey for the lost-parcel pilot and a card sort with 50+ agents across markets.
  • Dos direcciones de prototipos en código: una visión personalizada y otra con componentes nativos de Amazon Connect.Two coded prototype directions: a custom vision and one using native Amazon Connect components.

Aprendizajes claveKey learnings

  • La IA amplifica el criterio de quien la dirige: la calidad del diseño importa más que la velocidad.AI amplifies the judgment of the person directing it: design craft matters more than speed.
  • Figma puede servir para comunicar la intención con bocetos, mientras los prototipos interactivos facilitan el feedback de stakeholders.Figma can communicate intent through sketches, while interactive prototypes make stakeholder feedback easier.
  • Los sistemas de diseño deben ser legibles para los modelos de lenguaje: la IA comprendió mejor el de Amazon Connect que el sistema interno.Design systems need to be LLM-friendly: AI understood Amazon Connect’s system better than the internal one.

DescripciónDescription

Definición del problemaProblem statement

La IA necesita tokens, APIs, documentación y estructuras coherentes; las diferencias entre diseño y código y la falta de gobernanza pueden generar errores y divergencias.AI needs consistent tokens, APIs, documentation, and structures; design–code mismatches and missing governance can lead to errors and drift.

Qué creéWhat I created

Una guía de evaluación de 0 a 5 para arquitectura de tokens, APIs de componentes, paridad diseño–código, estructura, gobernanza y preparación de flujos con IA.A 0–5 assessment guide covering token architecture, component APIs, design–code parity, structure, governance, and AI workflow readiness.
